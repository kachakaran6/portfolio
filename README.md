# Karan Kacha — Portfolio

A personal developer portfolio built with modern web technologies, showcasing full-stack web applications, mobile apps, and technical skills.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animation & 3D**: Three.js, React Three Fiber, Anime.js
- **Icons**: Lucide React, Simple Icons

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## Build

To create an optimized production build:

```bash
npm run build
```
